# Movie Organizer: Features

> ## Excerpt
> Organize movies. Movie organizer. movie organizer, organize movies, DVD Organizer, movie catalog, movie collector, movie database

---
Movienizer is a feature-rich movie organizer designed to be useful both for people that watch movies occasionally and for true fans of movies and TV series. This is possible due to simple intuitive controls, informative lists, and lots of options and adjustments for advanced users. Adding movies to your collection can be as easy as pressing the "Add movie" button and selecting the most convenient method. Still there are many more things one can do with the program. Just check the list below and click on links to get more information about the corresponding feature. Each link refers to its own feature.

_Hint: You can also browse [articles by categories](https://www.movienizer.com/articles-by-categories.htm)_.

-   Add movies and [TV series](https://www.movienizer.com/help/adding-tv-series.htm) to your collection. This can be done in several ways: you can add movies by [title](https://www.movienizer.com/help/add-movie-titles.htm), by [barcode](https://www.movienizer.com/help/add-movie-barcodes.htm), from [files and folders](https://www.movienizer.com/help/add-movies-from-files-and-folders.htm), from [DVD/Blu-ray discs](https://www.movienizer.com/help/add-dvd-blu-ray-movies.htm) or folders.
-   [Add actors](https://www.movienizer.com/help/add-persons.htm), directors, screenplay writers, composers.
-   Download information about [movies](https://www.movienizer.com/help/download-information-about-movies.htm) and [persons](https://www.movienizer.com/help/download-information-about-persons.htm) from the internet. Get [information in your language](https://www.movienizer.com/help/supported-online-movie-databases.htm). Customize [download settings](https://www.movienizer.com/help/download-options.htm).
-   Manage [several databases](https://www.movienizer.com/help/use-several-movie-databases.htm).
-   Add several versions or [editions](https://www.movienizer.com/help/editions-of-movies.htm) of movies.
-   **Play movies** directly from the program using the [built-in](https://www.movienizer.com/help/built-in-video-player.htm) or any [external player](https://www.movienizer.com/help/external-video-player.htm).
-   [Create snapshots](https://www.movienizer.com/help/create-movie-snapshots.htm) from your videos and save them to the database automatically.
-   Change [status of movies](https://www.movienizer.com/help/status-of-the-movie.htm), marking them as seen, in collection, for sale, wanted.
-   Assign your own [movie rating](https://www.movienizer.com/help/movie-rating.htm) or use downloaded ratings.
-   [Sort the main list of movies](https://www.movienizer.com/help/sorting-movies.htm) in different ways. Use the "[Collection](https://www.movienizer.com/help/collection-sort-your-movies.htm)" tab to create [your own sorting patterns](https://www.movienizer.com/help/customize-collection.htm).
-   Export and [print information](https://www.movienizer.com/help/reports-export-and-print-movie-info.htm) about your movie collection using reports. Create [your own report](https://www.movienizer.com/help/report-builder.htm) templates. [Print any page](https://www.movienizer.com/help/print-any-page.htm) shown in the program.
-   Display [statistics](https://www.movienizer.com/help/movie-statistics.htm) for your movies.
-   Create illustrated movie catalogs for hardware players: [Dune HD](https://www.movienizer.com/articles/create-a-movie-catalog-for-dune-media-players.htm), [Popcorn Hour A-400](https://www.movienizer.com/articles/movie-catalog-popcorn-hour-a-400.htm), [Google TV and WD TV](https://www.movienizer.com/help/create-movie-catalog-for-wd-tv-and-google-tv.htm).
-   Easily find movies using the powerful [search](https://www.movienizer.com/help/search-your-movie-collection.htm), [quick filters](https://www.movienizer.com/help/quick-filters.htm), [quick search](https://www.movienizer.com/help/quick-search.htm), [extended filters](https://www.movienizer.com/help/extended-filters.htm).
-   [Add your own information](https://www.movienizer.com/help/add-or-edit-information-manually.htm) about movies and actors or edit the existing details.
-   Use [custom fields and lists](https://www.movienizer.com/help/custom-fields-and-lists.htm) to create any additional categories.
-   Protect your database with a [password](https://www.movienizer.com/help/movie-database-password.htm).
-   [Back up and restore](https://www.movienizer.com/help/backup-and-restore-database.htm) your database.
-   Apply actions to several movies or people at once using [Group Operations](https://www.movienizer.com/help/group-operations.htm).
-   [Change appearance](https://www.movienizer.com/help/user-interface.htm) by using different interfaces.
-   Import information from other movie catalog programs using plugins or import from a CSV file. [Import from All My Movies](https://www.movienizer.com/help/import-your-movie-catalog-from-all-my-movies.htm).
-   Adjust behavior of the program in the "[Options](https://www.movienizer.com/help/options-menu.htm)" menu.
-   Track movies you gave your friends using the built-in [Loan Manager](https://www.movienizer.com/help/loan-manager.htm).
-   Extend features of the program with [plugins](https://www.movienizer.com/help/plugins.htm).
-   Display menus, messages and other details [in your language](https://www.movienizer.com/articles/translating-movienizer-into-your-language.htm).

Some plugins are distributed with the program:

-   [Path Changer](https://www.movienizer.com/articles/change-paths-to-movie-files.htm). Change paths to your files easily if you moved your videos to a different location.
-   [Video File Renamer](https://www.movienizer.com/articles/video-file-renaming-plugin.htm). Rename and sort your video files using information from Movienizer.
-   [Export to Windows Media Player](https://www.movienizer.com/help/export-to-windows-media-center.htm). If you have a version of Windows including Media Center, you can create covers and descriptions for your movies in the format that Media Center can read and understand.

Not sure where to start? Just check the "[Quick start](https://www.movienizer.com/help/quick-start.htm)" section for basic usage instructions!
