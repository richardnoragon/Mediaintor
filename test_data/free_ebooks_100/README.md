# Free ebook test collection — 100 titles

Source: [Project Gutenberg](https://www.gutenberg.org/), downloaded through its [documented rsync mirror](https://www.gutenberg.org/help/mirroring.html) at `rsync.ibiblio.org::gutenberg-epub`. Retrieved 2026-09-20.

The selection contains 100 distinct English-language titles across 26 genre/category tags. EPUB is present for every title; 10 also have downloaded MOBI editions and 10 also have PDF editions converted locally from EPUB using Calibre 9.2.1. These are 120 files grouped into 100 book records, not 120 books. Genres are curated broad labels, not an authoritative taxonomy.

Gutenberg catalog records label these editions public domain in the USA. Selection excluded listed contributors with death dates after 1955; this catalog screening is not a worldwide rights certification. Original ebook licence notices are retained.

Target library: `/home/sproket01/Calibre Library`. Batch tag: `mediainator-test-100`. Each record has a `gutenberg` identifier and a genre tag. The existing Quick Start Guide is preserved.

`manifest.json` records title, authors, genre, source page, format origins, Calibre IDs, sizes, and SHA-256 hashes. `verification.json` records the completed import checks; `import.log` contains command results. `library_before_import/` is the pre-import backup. Staging downloads and conversion logs are temporary under `/tmp/mediainator-100-books`.

File structure/signature validation and import checks do not prove readable rendering, correct pagination, or full M1 acceptance. Representative EPUB/MOBI/PDF readability/navigation and sequential bookmark checks passed; the actual application’s 100-book UI checks remain to do. Initial parallel-launch annotation lock errors remain unresolved. Converted PDFs provide reflowed-text PDF samples; scanned/image-only PDFs are not covered.
