# M10-04 — restoration, startup and Last Session

**Core integration complete in development code. M10-G OPEN.** No installed candidate upgraded.

- Management dialog now offers Restore, Use at startup, Restore Last Session and Startup: Last Session.
- Startup resolves the saved choice; missing workspace storage initializes from existing settings without resetting them.
- A 250 ms controller detects supported structure/context changes and atomically updates Last Session only when changed, independently of named snapshots. Shutdown flushes the pre-teardown layout.
- Restore opens/closes supported Book-inator tabs, restores active tab and geometry, and resolves selected-book context by library/book UUID after catalog loading. Shared filters remain unchanged; hidden selections show an explanation and can be revealed through the existing Clear All action.
- Restore rejects critical operations, reviews draft edits before structural changes, and never launches, closes or repositions external readers. Basic available-screen bounding is implemented.

Verification: full regression suite **196 tests passed**, then the additional UUID/hidden-filter selection test passed with all five focused restore tests. Tests cover named startup, Last Session independence, module restore with untouched reader, busy rejection, Cancel preserving layout, corrupt-file preservation and UUID-based hidden selection without filter mutation. [Full run](m10_04_regression.txt).
