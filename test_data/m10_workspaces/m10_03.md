# M10-03 — workspace storage and named management

**COMPLETE in development code; M10-G OPEN.** No installed environment upgraded.

Implemented owner-scoped schema-v1 workspaces.json, a 1 MiB bounded regular-file reader, validation of identities/names/modules/geometry, corruption preservation, locking and revision checks, and QSaveFile commits with direct-write fallback disabled. Operations support five named snapshots, explicit overwrite, replacement with a new ID, rename preserving saved_at, deletion, and startup-reference fallback. Last Session and startup-setting storage APIs are ready for M10-04; no automatic restore/startup integration is claimed.

Hub Workspaces → Manage named workspaces provides Save new, Overwrite, Rename, Delete and Reload. Duplicate names require explicit overwrite confirmation; capacity requires user replacement selection or Cancel. Library operations block management changes. Capture includes supported tabs, active tab, geometry and library/book UUID context only, excluding filters and reader state. Damaged files disable mutations rather than being overwritten.

**192 regression tests passed**, including seven workspace tests covering capacity/replacement/startup references, timestamp preservation, last-session independence, stale revisions, ownership, malformed/oversize files, duplicate names, cancelled UI save, unchanged shared preferences, and failed open/partial write/failed commit with original bytes retained.
